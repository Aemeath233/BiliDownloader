# 蓝白角色图标 · 2.1.2

使用用户选定的蓝白长发角色原图，保留人物画面并增加透明安全边距。原图保存在 `artwork/sky-blue-ribbon.png`。

- `logo.ico` 包含 16、24、32、48、64、128、256 像素图像，供程序窗口、EXE、安装程序和安装后快捷方式使用。
- 侧栏使用 `bili_client/desktop/assets/brand.png`，由内嵌 HTML 转成 data URL，无网络图片依赖。
- 保留现有页面主题，未改动下载与账号行为。
