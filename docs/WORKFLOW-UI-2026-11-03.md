# 下载操作与界面调整 · 2.2.0

本轮针对下载时的实际操作距离与页面跳动调整前端。设计依据来自本对话：Windows 双击使用、以下载为核心、希望轻巧自然，并使用已选定的蓝白动漫头像。

## 布局与视觉

采用蓝白工具界面：深蓝文字 `#20344b`、蓝色操作 `#087eae`、浅蓝选中背景 `#e6f3fb`、白色内容区域与淡蓝灰侧栏。继续使用 Windows 系统中文字体，无需下载字体。导航、页面标题和底栏保持在窗口中，内容在各自区域滚动；主操作区固定在解析结果底部。

单视频省略分集选择，直接显示下载内容和画质。合集使用分集列表与品质选项并排布局。短窗口压缩标题与间距，保持内容切换、画质、目录选择与下载按钮可操作。文件名预览折叠在选项中，完整路径与标题可悬停查看。

解析前后保持输入框尺寸稳定，解析后将“解析链接”降为次要按钮，突出“开始下载”。页面切换只保留短暂淡入；通知移动到底栏右侧，避免遮挡目录或下载按钮。已完成任务将文件大小归入元信息，减少重复状态和行高，打开、定位、移除继续使用明确的图标按钮。

## 操作行为

- 粘贴链接后自动解析，也可按 Enter；输入法选字、Shift+Enter 不触发解析。
- 顶栏直接扫码登录；已有凭证时进入账号设置。
- 本次目录通过原生文件夹选择器更改，仅保存在当前解析结果中；取消选择不会改变目录，下一次解析恢复默认目录。不会覆盖设置页未保存的字段。
- 下载时冻结本次选择与链接；添加成功后清除任务列表的旧搜索和状态筛选，使新任务可见。
- 勾选分集、切换当前品质参考分集时保留列表滚动位置；翻页回到列表顶部。
- 切换页面保留列表位置；“新建下载”打开空白并聚焦的链接输入框。

后端新增受限命令 `choose_destination`：只接收解析结果 ID，由原生选择器返回路径；解析结果过期或程序退出后拒绝写入。预览和创建任务共用既有目录覆盖逻辑，下载、账号与持久化实现保持原有流程。

## 验证

完整 Python 回归 149 项通过，包括新增的目录覆盖、默认目录隔离、取消选择和解析结果过期检查。原生 WebView2 在常规窗口和最小窗口中验证下载流程、控件可见性及命中、目录选择、单视频简化、筛选重置、滚动保留、音视频模式、主题、键盘与关闭保护；完整结果见 `workflow-ui-verification.json`。
