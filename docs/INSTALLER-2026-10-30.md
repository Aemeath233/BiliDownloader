# 安装版与体积优化

默认交付改为 `dist/installer/BiliDownloader-Setup.exe`。最终包约 20.61 MiB，程序自身安装后约 50.70 MiB；不包含系统共享 WebView2 的占用。安装时展开一次，后续从安装目录加载，不再每次启动释放 Python、FFmpeg 和浏览器运行时。

此前完整便携包约 401 MiB，主要额外携带固定版 WebView2；标准便携包约 104 MiB，仍含全功能 FFmpeg。新安装版复用系统 WebView2，将 FFmpeg 改为从固定源码编译的约 2.18 MiB 静态工具，保留下载器实际用到的无损封装与音频探测，不含转码编码器和网络协议。原有画质选择与 Python 下载服务保持原实现。

安装向导支持简体中文，当前用户安装，无需管理员权限；具备桌面、开始菜单快捷方式和系统卸载入口。缺少 WebView2 时，在安装阶段提示并使用微软签名的 Evergreen 小型引导程序联网补齐。程序运行时不下载组件。卸载保留账号、设置、历史和视频，不移除共享 WebView2。

验证均使用临时安装目录、隔离 APPDATA 和合成媒体/用户数据；没有操作真实账号或视频。结果：

- 实际 Setup 安装、桌面/开始菜单快捷方式、卸载注册信息通过。
- 三次从真实安装目录启动，到前端与 Python 完成握手：1.301、1.161、1.126 秒。这是本机连续测量，不是其他设备的速度承诺。
- 三次启动均完成包内 FFmpeg 真实合并，且没有单文件依赖解包。
- 覆盖升级清除合成旧依赖文件，保留合成下载视频与用户数据。
- 卸载移除程序、快捷方式与卸载注册信息，保留合成视频与用户数据。
- 10 组媒体兼容检查通过：H.264/HEVC/AV1 + AAC、H.264 + E-AC-3/FLAC、无音轨视频、旧 FLV，以及原始 AAC/E-AC-3/FLAC。封装流逐包 SHA256 相同；原始音频转换封装后解码样本相同。
- 138 项 unittest 全通过；Ruff 检查及 68 个 Python 文件格式检查通过。

安装包、FFmpeg 许可证、固定源码、配置、校验文件位于 `dist/installer/`。可复核数据见 `installer-verification.json`。当前只验证了已有系统 WebView2 的安装路径；尚未在无运行时的干净虚拟机验证联网补齐，也未使用真实账号执行网络下载。没有上传 GitHub Release。
