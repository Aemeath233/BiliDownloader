# 界面打磨（2.1.1）

- 单条任务的打开、定位、重试、重选、取消和移除使用带图标、有边界的按钮。打开/重试使用强调色，移除提示仅删除记录、不删除文件。按钮顺序在任务状态变化后保持一致。
- 队列统一使用一个列表面板和轻分隔线；勾选任务立即显示选中底色。
- 标题、下载模式/品质、文件路径分别显示；完整路径可悬停查看。已完成任务收起进度条和重复的 100% 数字，显示已保存及文件大小。
- 状态使用带圆点的文字标记；筛选、次要操作、折叠入口、设置页边界和保存区域使用统一样式。保持键盘焦点和减少动态效果设置。
- 标准窗口及最小窗口中的实际 WebView2 流程均通过；最终标准窗口流程 19 项检查通过。已检查队列、设置页的浅色/深色渲染结果。
- 最终安装包生成成功，包内资源与源码一致；隔离配置/受限 PATH 下包内应用约 1.02 秒就绪，真实 FFmpeg 合并和退出检查通过。没有覆盖当前用户安装或真实账号数据。

安装包位于 `dist/installer/BiliDownloader-Setup.exe`，校验值位于同目录 `SHA256SUMS.txt`。截图为演示数据，见 `images/ui-polish-queue.png`。

动漫娘头像通过内置 imagegen 单独生成候选稿，本次界面构建继续使用现有应用图标。
