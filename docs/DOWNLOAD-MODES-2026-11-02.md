# 下载内容选择（2.1.0）

添加任务页提供「视频＋音频」「仅音频」「仅视频」三个选项。默认下载完整视频；仅视频会提示无声，保存为 MP4。仅音频显示账号实际可获取的音频品质，保存为 M4A 容器并保留源编码，不转 MP3。

设置中的「默认下载内容」作用于下次解析。任务页临时切换只影响当前批次。任务记录新增 `download_mode`，旧记录缺少此字段时按完整视频恢复；重试、批量重试和重选品质保留模式。不同模式分别判断重复任务，保存文件仍避开同名文件。

DASH 资源仅下载选中的媒体流；仅音频不探测或下载视频流，仅视频不探测或下载独立音轨。音频列表按实际返回的独立轨道展示，包含可用的普通音频、Dolby 或 FLAC，取流时再次校验所选档位，缺少时停止，不自动替换。旧式合流资源需要下载原流再提取轨道，音频选项会明确提示；原有分段、权限和预览限制继续生效。

输出通过 FFmpeg 显式选择单一音频或视频轨道；单轨模式的进度显示「保存中」。队列标记下载内容，已完成的 M4A 可以使用系统默认音频播放器打开。未增加新运行时或转码库。

验证结果：146 项 unittest 通过；完整/音频/无声视频、旧任务默认值、重试、模式重复判断、音频缓存隔离、配置存储通过。15 组真实本地媒体检查通过，包括从合流素材提取音频或无声视频，并验证被排除轨道为空、所保留轨道的包哈希不变。实际 WebView2 的模式切换、品质列表、文件名预览、入队、临时选择恢复默认通过；检查了标准窗口与最小窗口截图。

最终安装包生成成功；包内应用在隔离配置、受限 PATH 下启动约 1.04 秒就绪，包内 FFmpeg 合并及退出检查通过。没有覆盖用户当前安装；尚未使用真实账号执行 B 站网络下载或会员音轨测试。测试中的资源、音频品质和队列均为演示数据，实际档位取决于接口与账号权限。

安装包：`dist/installer/BiliDownloader-Setup.exe`。校验值位于同目录 `SHA256SUMS.txt`；复核数据见 `download-modes-verification.json`。
